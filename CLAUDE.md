# gde-benz

Личный Telegram-бот (Spring Boot, long-polling) для получения **актуального наличия топлива**
на ближайших АЗС по геолокации пользователя. Источник данных — `gdebenz.ru/api/nearby`
(краудсорсинговая карта наличия; доступ согласован с автором сервиса).

## Рабочий пайплайн итераций

Тестировать бота в Telegram локально НЕЛЬЗЯ (Telegram недоступен на территории РФ),
поэтому проверка идёт только на сервере после деплоя.

Каждый пункт плана проходит строго по шагам:

1. **Обсуждаем** пункт плана (дизайн, развилки, решения).
2. **Аппрув** от пользователя (krasovsky) — без него к реализации не переходим.
3. **Реализация** — Claude пишет код по согласованному пункту.
4. **Commit + push** в GitHub.
5. **CI/CD (GitHub Actions)** собирает и деплоит на сервер.
6. **Проверка в Telegram** — пользователь лично проверяет бота в ТГ (на задеплоенной версии).

Правила:
- Не забегать вперёд: никакой реализации до аппрува (шаг 2).
- Не переходить к следующему пункту, пока текущий не проверен в ТГ (шаг 6).
- Держать изменения небольшими — один пункт плана за итерацию.
- Локальный `docker build` допустим как проверка сборки перед пушем; локальный `up`
  для проверки бота бесполезен (нет доступа к Telegram API).

## Принятые решения

- **Хранение:** Postgres через Spring Data JPA — делаем сразу «по-нормальному» (не in-memory).
- **Ввод адресом:** не поддерживается — только шаринг геолокации из Telegram.
- **Live-локация:** планируется к реализации (обновление выдачи по мере движения).
- **Приватность:** бот приватный — доступ по белому списку Telegram user-id; чужим API не дёргаем.
- **Источник данных:** `gdebenz.ru/api/nearby` за DDoS-Guard → нужны браузерный `User-Agent`
  и `Referer: https://gdebenz.ru/`, общий cookie-jar (`__ddg*`), без `Accept-Encoding: gzip`.
  Ходить вежливо: запрос по действию пользователя + короткий TTL-кэш, бэкофф на 5xx.

## Формат ответа `/api/nearby`

`GET https://gdebenz.ru/api/nearby?lat=<D>&lon=<D>&radius_km=<D>&_=<ts>` →
`{ "stations": [ ≤200 ], "updated": "yyyy-MM-dd HH:mm:ss" }` (время МСК).

Станция: `osm_id`, `brand`, `name`, `addr`, `lat`, `lon`, `distance_km`,
`status` (`yes`/`no`, возможны др. → fallback UNKNOWN), `detail` (человекочит., вкл. очередь),
`fuels_now` (что есть сейчас: `92,95,95+,98,100,ДТ`), `confirmations` (int),
`last_at` (МСК), `confidence_base` (0..1), `meta.f[]` (марки на АЗС: `92,95,98,100,80,dt,lpg`).

Собирая URL — форсировать `Locale.ROOT` (иначе ru-локаль даст запятую в координатах).

## Стек

Spring Boot 4.1.1, Java 21, telegrambots (rubenlagus) 10.3.0 long-polling,
Spring Data JPA + PostgreSQL (H2 в тестах).
